# FinSight — Intelligent Flow

A responsive, animated fintech dashboard concept with a misty silver-blue glass aesthetic, teal luminous accents, animated orb, KPI cards, transaction chart, recent activity, transaction table, and CSV export.

## Live demo

Once the first successful **Deploy FinSight to GitHub Pages** workflow completes, visit: https://rineeverma2006.github.io/finsight-project/

## Data note

This is a front-end demo with illustrative sample metrics and transactions. It is not connected to a production bank, live banking data, authentication, or the earlier FastAPI backend. Non-overview navigation items currently show a demo preview; CSV export downloads the visible sample table.

## Run locally

Open `index.html` in a browser, or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.
